Under the hood

Rule-based, not an AI call

No API key, no sign-up, no server. A set of plain rules does the rewrite in your browser: strip filler openers, cut hedge words, pull out the role, format, length, audience and tone, then rebuild the prompt in a fixed structure.

Why structure wins

Models do better with a clear role, one task, and a stated output. A vague ask like “write something about dogs” leaves the model guessing the format, length and reader. The rewrite makes each of those explicit, with a bracketed placeholder where you still need to decide.

The clarity score

Eight checks, each worth a share of 100: a role, one clear task, context, output format, length, audience, tone, and a constraint or example. Before and after are scored the same way, so you can see the gain from the rewrite itself.

Make it yours

When several people grade with the same prompt, the results come out alike. The three modes change that: Keep it similar tightens your prompt as written, Balanced swaps one thing for a different angle, and Entirely different rebuilds it with a new role, format, tone, audience and a twist. Each click of Entirely different gives a new combination, so the same starting prompt produces a different rewrite every time.
